# Výpočet dvojného integrálu v polárních souřadnicích

 Pomocí substituce $x = \rho \cos \varphi$ a $y = \rho \sin \varphi$ dostaneme pro spojité funkci $z = f(x, y) = f(\rho \cos \varphi, \rho \sin \varphi) = g(\rho, \varphi)$. Platí:

$$\iint_{A} f(x, y) \stackrel{~~dxdy~~}{=} \iint_{\bar{A}} g(\rho, \varphi) \cdot \rho \stackrel{~~d\rho d\varphi~~}{}$$
