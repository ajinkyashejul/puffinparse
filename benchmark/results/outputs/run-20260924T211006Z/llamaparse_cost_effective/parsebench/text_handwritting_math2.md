# Výpočet dvojného integrálu v polárních souřadnicích

 Pomocí substituce $x = \rho \cos \varphi$ a $y = \rho \sin \varphi$ dostaneme pro spojitou funkci $z = f(x, y) = f(\rho \cos \varphi, \rho \sin \varphi) = g(\rho, \varphi)$. Platí:

| Expression                           |                                                                                |
| ------------------------------------ | ------------------------------------------------------------------------------ |
| $$\iint\_{A} f(x, y) \\, dx \\, dy$$ | $$= \iint\_{\overline{A}} g(\rho, \varphi) \cdot \rho \\, d\rho \\, d\varphi$$ |
